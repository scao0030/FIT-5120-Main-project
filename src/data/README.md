# /src/data/

This directory contains all data assets for the **DigiNav** platform — a digital literacy tool helping older Australians navigate essential online services.

Data is organised into two layers following a standard data engineering workflow:

```
src/data/
├── raw_data/          ← Source files. Read-only. Never modify directly.
├── clean_data/        ← Processed, analysis-ready files. Generated by notebooks.
└── README.md          ← This file
```

---

## Data Pipeline Overview

```
Source (Open Data Portals)
        │
        ▼
raw_data/              ← Downloaded as-is. Preserved for reproducibility.
        │
        ▼
src/notebooks/         ← Jupyter notebooks clean, transform, and combine
        │
        ▼
clean_data/            ← Output CSVs consumed by the frontend and database
        │
        ▼
AWS RDS PostgreSQL     ← Production database (loaded by technical team)
```

All processing is done in Python (pandas, pgeocode, numpy) via Jupyter notebooks located in `src/notebooks/`. Raw files are never modified in place.

## Important Rules

- **Never edit files in `raw_data/` directly.** They are the source of truth.
- **Never commit API keys or credentials** to this directory.
- All output files in `clean_data/` are fully reproducible by re-running the notebooks from raw sources.
- When a new version of the AIHW dataset is released (annually, each October), add it to `raw_data/` with a versioned filename — do not overwrite the previous file.
